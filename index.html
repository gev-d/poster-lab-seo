What is PosterLab?

PosterLab is a lightweight “mini SaaS” experience: clean pages, honest navigation, and a simple editor that updates a live preview. It is intentionally built as separate HTML files so you can see how titles, headings, and internal links work before moving to SPAs or frameworks.
